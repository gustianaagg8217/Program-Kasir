## 💡 Key Implementation Details

### Invoice Number Generation
```
Format: INV-YYYYMMDD-HHMMSS
Example: INV-20260428-143022
Unique: Guaranteed unique (part of invoice_number unique constraint)
```

### Automatic Creation Flow
```
1. Transaction completes (existing)
2. Receipt generated (existing)
3. Invoice created from transaction data (NEW)
4. PDF generated from invoice (NEW)
5. All files saved (NEW)
```

### Database Tables
```sql
invoices (header info)
├─ invoice_number (unique)
├─ total, bayar, kembalian
├─ discount_percent, discount_amount
├─ tax_percent, tax_amount
└─ created_at (with index)

invoice_items (line items)
├─ invoice_id (foreign key, indexed)
├─ nama, qty, harga_satuan, subtotal
└─ One row per item
```
